# 📱 Nexa AI - Pure Native Kotlin (Android Installation Guide Bina PC Ke)

Aap bina computer ya laptop ke direct apne phone se ye APK generate aur install kar sakte hain!

---

### 🚀 Tareeqa: GitHub Actions Se 1-Click APK Download (0 PC Required)

1. **GitHub Par Repo Open Karein**:
   - Apne phone ke browser me apna GitHub repository open karein: `https://github.com/Chandanlohave/Nexa-Core-Demo-UI`

2. **Actions Tab Par Jayein**:
   - Repository ke upar **"Actions"** tab par click karein.
   - Wahan aapko **"Build Nexa Android APK"** workflow dikhega.

3. **Run Workflow (Agar Auto-run na ho)**:
   - "Run workflow" button click karein.
   - 2 se 3 minute ke andar GitHub ka cloud server pure Kotlin code ko compile karke APK ready kar dega.

4. **APK Download Karein**:
   - Completed workflow run par tap karein.
   - Niche **"Artifacts"** section me **`Nexa-AI-Android-App`** link milega.
   - Us par tap karte hi `app-debug.apk` aapke phone me download ho jayegi.

5. **Phone Me Install Karein**:
   - Downloaded APK par tap karein aur **"Install"** dabayein.

---

### ✨ Included Native Features:
1. **Zero UI Change**: React wala hi pure native Jetpack Compose me Glowing Orb, Radar Rings, aur Matrix Rain Canvas.
2. **Gemini Live Screen Sharing**: Native `MediaProjection` background service jo aapke phone ki screen ko capture karke real-time Gemini Multimodal WebSocket ko stream karti hai.
3. **Floating UI Support**: Screen share ke waqt aap YouTube ya koi bhi app chala sakte hain aur Nexa live guidance degi.
